# fap-logs — диагностика EP6 THP по логам FAP

Набор скриптов для самостоятельной диагностики двигателя EP6 THP (Citroen C4 II седан,
1.6 THP 150, ЭБУ Bosch MED17.4.2) по CSV-логам, выгружаемым сканером FAP через ELM327.

Проект вырос из фактического кейса: активная ошибка P2279 (Turbocharging circuit
Suspected leak) при здоровых показаниях по остальным каналам. Все нормы в скриптах —
сводка практики EP6 (drive2/UltraDed, autoprogs, EuroMotor) плюс нормы, выведенные
из здоровых дней наблюдения 05–10.10.2026.

## Состав проекта

| Файл | Назначение |
|---|---|
| `car_merge.py` | Склейка повторных выгрузок суточного лога в канонический файл. Дедупликация, сортировка Дата+время, перенос исходников в `raw/`. Идемпотентен: повторный запуск ничего не меняет. |
| `car_norms.py` | Сверка логов с нормами EP6: MAP на ХХ, лямбды, масло, ТНВД, откаты зажигания, детонация. Теги `[ok] / [~] / [!!]`. |
| `logscan.py` | Статистический разбор CSV: медианы, выбросы, плотность записи, кондиционер, батарея. Результат — `отчёт_logscan.txt`. |
| `car_kb.py` | База знаний по машине (`car_kb.json`): add / show / sync / brief / backup / del. |
| `car_repair.py` | Спасение побитой базы: построчная реконструкция JSON с сохранением `.broken.json`. |
| `car_kb.json` | Данные: авто, сканер, диагностика, план, наблюдения, метрики по дням. |
| `шпаргалка_скрипты.md` | Инструкция по порядку работы и все нормы v3. |

## Порядок работы после поездки

1. Выгрузить CSV из FAP в эту папку (несколько выгрузок одного дня — нормально);
2. `python car_merge.py` — склеить день (только если появились новые файлы);
3. `python car_norms.py` — сверка с нормами;
4. `python logscan.py` — подробный разбор (опционально);
5. `python car_kb.py sync` — влить метрики дня в базу.

## Что в базе знаний

- хронология дефекта P2279: замена втулки патрубка 11.10, появление кода ~19:22:15
  на холодном ХХ, паттерн «мелкий подсос после дросселя» (нижняя лямбда беднеет только
  на ХХ, верхняя смещена вниз), интермиттент;
- главный дневной маркер больной части дня — доля точек нижней лямбды < 200 мВ;
- важные нюансы: флаг Errors в CSV — наличие DTC в памяти, а не активность в моменте;
  MAP на ХХ считается только без кондиционера (idle-up задирает MAP до 470+);
  просадки ТНВД в накатах — норма отсечного режима, статистика только при дросселе >= 20%;
- код P2279 НЕ стирать до диагностики.

## Ограничения

- логи CSV в репозиторий не входят (конфиденциальность + объём);
- нормы MAP 300–400 и лямбда 420–460 мВ выведены из здоровых дней, не из мануала PSA;
- инструменты (logscan v2.2 / car_norms v3.1) сверены между собой: медианы сходятся
  с точностью до разных границ определения ХХ.

## Версии
